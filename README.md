# MLPR — определение роли участника судебного дела по ИНН

Программный модуль для автоматической классификации процессуальной роли участника судебного документа (истец / ответчик / третье лицо) по его ИНН с использованием LLM.

## Задача

На вход подаются размеченные судебные документы в формате JSONL. Для каждого участника документа, идентифицированного по ИНН, модель должна определить его процессуальную роль в деле.

## Технологии

- **Python**
- **LLM**: Qwen2.5-3B-Instruct, развёрнута локально через [llama.cpp](https://github.com/ggerganov/llama.cpp) (`llama-server`)
- **openai** — клиент для обращения к локальному серверу через OpenAI-совместимый API
- **scikit-learn** — оценка качества модели (accuracy, confusion matrix, classification report)

## Как запустить

1. Запустить локальный LLM-сервер:
```
C:\llama\llama-server.exe -m C:\Users\User\PyCharmMiscProject\model\qwen2.5-3b-instruct-q5_k_m.gguf -c 4096 -ngl 99 --host 127.0.0.1 --port 8080
```

2. Запустить `mlpr.py`:
```
python mlpr.py
```

Файл с разметкой `annotations.json` уже включён в репозиторий.
